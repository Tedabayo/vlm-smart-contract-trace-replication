# Evaluating Evidence Representations for AI-Based Ethereum Smart Contract Vulnerability Analysis

This repository is being prepared to host supplementary research materials for the master's thesis *VLM-Assisted Smart Contract Execution Trace Understanding*.

The study covers 20 historical Ethereum exploit incidents, three AI model families, five evidence conditions, and 300 archived model responses.

## Publication status

**The research-data archive has not been published yet.** A redacted results-and-trace archive is undergoing final disclosure review. A downloadable GitHub Release will be added here only after that review is approved.

## Scope of the planned archive

The planned release preserves saved model responses, researcher-assigned scoring records, selected execution-trace evidence, and offline integrity and aggregate-verification scripts.

The saved scoring records reproduce **172/300** correct vulnerability classifications and **151/172** full-credit reasoning/localisation results among correctly classified responses. These numbers reflect the archived researcher's assessments, not an independent re-adjudication.

Some original third-party Solidity/Vyper sources and source-containing model inputs are withheld because redistribution rights or required notices could not be established. The public archive will therefore support checking saved results, **not a complete standalone rerun of all model queries**. Hashes and retrieval information for omitted material are retained in its redaction manifest.
